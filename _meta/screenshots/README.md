# Documentation images

This directory contains screenshots used to illustrate Legio. Runtime assets belong in `src/assets` or `src-tauri/icons`, not here. Reference images with relative Markdown paths and descriptive alternative text. Update screenshots when the interface they illustrate changes; they are not automated visual baselines or release acceptance evidence.

## Component previews

`previews/settings-downloads-dark.png` and `previews/settings-downloads-light-error.png` show the settings dialog in dark and light palettes. These are Chromium component previews at 1440 x 1000 with native IPC stubbed, not captures of the installed launcher. The light preview includes an operation error.

Before adding images, remove personal data, credentials and private source URLs, and check redistribution rights for third-party artwork. Do not place fonts, native dumps, temporary captures or unrelated design experiments in this directory.
