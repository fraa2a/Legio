The user approved both plans and inline execution with one independent final review. The PR remains draft until the affected Windows machine passes acceptance. No TaxLauncher migration or release merge is included.

## Independent review and corrections

The single read-only review reported no Critical or Minor findings and five Important findings. Each was accepted and addressed in one root fix pass:

1. Pin the already validated screenshot URL throughout download and publication. A controlled metadata-reordering resolver test returned screenshot B instead of the expected A before correction.
2. Treat recoverable corrupt metadata as a cache miss at the shared cache boundary and reach the existing repair path. The corrupt-cache regression failed before correction; an additional native artwork test checks that a missing header waits for metadata recovery and then displays its cached bytes.
3. Retain metadata requests per live consumer. Offscreen/unmounted rows release demand; the final consumer cancels the native request. Both a shared-consumer test and a mounted Store-row visibility test failed before correction.
4. Retain bounded recent cancellation IDs so cancellation before native registration cannot be forgotten. The cancel-before-begin test failed before correction.
5. Queue ordinary image conversion and IPC phase logs without waiting for log I/O. A subprocess holds the actual logger lock while converting and assembling artwork; it timed out before correction and completes after correction.

The reviewer could not certify Windows Dither composition, live blur correctness, native latency or artifact provenance from source and simulated graphics. The affected-machine visual and performance protocol is in `0.2.0-windows-test.md`; installer provenance is verified during artifact handoff. TaxLauncher migration and the other developer's transparency report are explicitly deferred.
