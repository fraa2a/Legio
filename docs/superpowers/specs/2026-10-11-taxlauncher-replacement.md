# TaxLauncher replacement design

Windows only. Deliver a TaxLauncher 1.5.0 bridge update through the existing latest.json installer mechanism. The bridge retains the legacy Electron name/user-data directory, exports games.json, tray-settings.json, download-config.json and an allowlist of renderer localStorage preferences before changing either application. No credentials or administrator state enter the export. Keep source JSON backups and unsupported legacy values outside the application installation directory.

Legio owns conversion into its native SQLite schema. A headless CLI imports into the installed production app-data path resolved from the Tauri configuration. Validate the entire input before writing and commit games, sessions, settings, source and migration receipt in one transaction. Stable legacy IDs and executable matching avoid duplicates on retries and preserve existing Legio games/settings. Convert playtime from minutes to milliseconds and retain last-played time. Infer Steam identity only from an explicit ID or a Steam CDN cover URL, never from a numeric TaxLauncher game ID or fuzzy title lookup. Missing games/executable paths remain preserved in backup and block replacement rather than silently disappear.

The bridge stages a pinned Windows Legio installer, verifies SHA-256, waits for TaxLauncher exit, installs Legio silently, invokes the import CLI and checks its receipt before uninstalling TaxLauncher. Installation/import failure leaves TaxLauncher installed and preserves the export. Never delete games, downloaded archives or the legacy data directory. Reject installations containing game/data paths inside the directory being uninstalled. Existing Legio installations must not be overwritten by a different build. The per-user TaxLauncher uninstaller must be the exact known file in its installation directory; never execute arbitrary registry commands.

Preconfigure https://source.taxphobia.top/store.json with a valid cached manifest. A bundled source snapshot allows offline import; normal Legio source refresh updates it. Preparation validates the manifest using Legio itself and pins installer version/hash. Build fails without prepared release payloads. Do not publish a feed, merge PR 183 or release Legio during implementation. Build/test a new Windows artifact for the importer before the eventual merge and production bridge release.

Keep application and network logging off by default. The replacement helper writes a dedicated bounded progress/error transcript and receipt needed for recovery. No source URLs with credentials, admin settings or executable paths are printed in ordinary diagnostics.
